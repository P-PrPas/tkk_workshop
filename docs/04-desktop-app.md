# 04 — Desktop App

## หน้าที่
ตอบคำถามของหัวหน้างาน: **"operator หยิบชิ้นงานไหนออกมาตรวจแล้วบ้าง"**
แกนเดียวกับพาร์ท 3–4 ของโน้ตบุ๊ก แต่ทำให้ **ใช้งานได้จริง** และวิทยากรรันโชว์

## สิ่งที่แอปทำแต่โน้ตบุ๊กไม่ทำ (นี่คือเนื้อหาของสาร)

### 1. Threaded inference — จอเดินตาม FPS ที่ detect ได้จริง
`Camera` (เธรดอ่านกล้อง) · `Analyzer` (เธรดหยิบเฟรมล่าสุด รัน YOLO + MediaPipe + กติกา
**วาดผลลงเฟรมเดียวกัน**) · `main` (แค่ `imshow` เฟรมที่ analyzer วาดเสร็จ + รับปุ่ม)
- จอกระตุกเท่า detect FPS แต่**กล่องอยู่บนเฟรมที่โมเดลคิด ไม่ลอยตามหลัง** — ขยับแก้วก็ตามทัน
  (เวอร์ชันก่อนโชว์วิดีโอสด 30fps + กล่องลาก → ดูเหมือน "detect ได้แค่ตอนอยู่นิ่ง")
- `main` เบามาก — inference ไม่บล็อกการรับปุ่ม/การแสดงผล
- **FPS ที่มุมจอ = detect FPS จริง** ไม่ใช่ FPS ของวิดีโอ · yolo11s บน **CPU ≈ 5 FPS**
  บน **CUDA ≈ 5ms** → ตอนเปิดแอปถ้าไม่เจอ GPU จะพิมพ์คำสั่งลง torch cu124 ให้
- `device:` เว้นว่าง = **auto** (`pick_device()` ไล่ cuda → mps → cpu) ไม่ต้องตั้งเอง · ใส่ค่าเมื่ออยากบังคับ
- ให้ auto เจอ GPU ต้องลง torch ให้ตรงเครื่องก่อน: **NVIDIA (Win/Linux)** torch cu124 (ไม่เกิน CUDA ใน
  `nvidia-smi`) · **Apple Silicon** torch จาก PyPI มี MPS มาแล้ว · **mac Intel / CPU ล้วน** ไม่มี GPU →
  `model_path: models/best.onnx` + `pip install onnxruntime` · ลด `imgsz` 480→384 ช่วยทุกทาง
- **ไม่มี CUDA บน macOS** — `pip install torch --index-url .../cu124` ไม่มี wheel ให้ mac (auto เลย fallback MPS/CPU)
- ตอนเปิดแอปพิมพ์ `YOLO device: ...` บอกว่า auto เลือกอะไร — เจอ GPU แต่ยังขึ้น CPU มักเพราะลง torch ตัว `+cpu`

### 2. Tracking ID + ความจำของแก้ว (`CupMemory`)
```python
r = model.track(frame, persist=True, tracker="bytetrack.yaml", imgsz=..., conf=..., classes=[...])[0]
cups.update([(int(tid), box) for box, tid in ...])   # เก็บกล่องล่าสุดต่อ track ID
cup_boxes = [box for _, box, _coasting in cups.boxes()]
```
- track ID → แต่ละแก้วมีเลขติดตัว "แก้ว #3 ถูกถือมา 4 วินาทีแล้ว"
- **`CupMemory`** — มือกำแก้วบัง object detection จนกล่องแก้ว**หาย** → เก็บกล่องล่าสุดต่ออีก
  `cup_memory_frames` เฟรม (~1 วิที่ 15 FPS) → กติกายังมีกล่องให้เช็ก · **ไม่วาดกล่อง coasting บนจอ**
  (โชว์เฉพาะ detection สด — กล่องผีทำให้ผู้ชมงง) แต่ทำงานเบื้องหลังเต็มที่
- **`hand_on_cup`** แทน "กำ + bbox ทับ" — **ไม่ดูว่ากำหรือแบ** (แก้วไม่มีหูต้องจับตรง ๆ
  มือดูเหมือนแบมือปกติ) ดูจาก: (1) มือกับแก้วขนาดใกล้กัน (`grip_max_size_ratio` กันมือชี้จากไกล)
  (2) จุด landmark >= `grip_min_points` จุดตกในกล่องแก้ว**ที่ขยายขอบ `grip_box_margin`** —
  มือห่อแก้วไม่มีหู จุดตกในกล่อง / แก้วมีหูจับที่หู มืออยู่ *ข้าง* กล่อง ต้องเผื่อขอบ ·
  `HoldState` (3/6) กันเฟรมที่วืบ
- `hand_state()` (FIST/OPEN/MID จากพาร์ท 2) ยังมี — ใช้ **ระบายสีโครงมือ** ให้ดูว่าโมเดล pose
  ทำงาน แต่**ไม่ได้ใช้ตัดสิน HOLDING** (นี่คือ teaching moment: กฎง่าย ๆ "มือกำ" ของโน้ตบุ๊ก
  พังกับแก้วจริง เลยเปลี่ยนสัญญาณ)

### 3. State machine + hysteresis
```python
class HoldState:
    """กันป้ายกระพริบ: ขึ้นยาก ลงยากกว่า"""
    def __init__(self, on_n, off_n):
        self.on_n, self.off_n = on_n, off_n
        self.hits = self.misses = 0
        self.holding = False

    def update(self, observed: bool) -> bool:
        if observed:
            self.hits += 1; self.misses = 0
            if self.hits >= self.on_n: self.holding = True
        else:
            self.misses += 1; self.hits = 0
            if self.misses >= self.off_n: self.holding = False
        return self.holding
```
ค่า on/off ไม่เท่ากันโดยตั้งใจ (3 ขึ้น / 6 ลง) — ถ้าเท่ากันจะยังกระพริบตรงขอบ
นี่คือ hysteresis และเป็นคำที่ควรพูดออกไปตรงๆ หน้าห้อง · ยังดูดซับเฟรมที่ pose วืบหายด้วย

### 5. เช็กลิสต์ผู้ตรวจ (`Inspection`) — โจทย์จริงของงาน
```python
class Inspection:
    def update(self, id_boxes, held_ids):
        ...
        self.hits[tid] = max(0, min(need, self.hits.get(tid, 0) + (1 if tid in held_ids else -1)))
        if self.hits[tid] >= need:
            self.picked.setdefault(tid, now)
```
- **ต้องถือสะสมครบ `pick_frames` เฟรมจึงติ๊ก** — โน้ตบุ๊กติ๊กทันทีที่มือแตะ (มือเฉียดผ่าน
  หน้าแก้วก็ติ๊ก) นี่คือปัญหาเดียวกับป้ายกระพริบ แค่คนละที่ · **ตัวนับแบบรั่ว** (+1 เมื่อจับ
  −1 เมื่อไม่จับ) ไม่ใช่ "ติดกัน N เฟรม" — หลุดเฟรมเดียวถอยแค่หนึ่ง ไม่ล้างทิ้ง
- **ติ๊กแล้วติ๊กเลย** วางคืนโต๊ะก็ยังตรวจแล้ว จนกว่าจะกด **เริ่มรอบใหม่**
- **เส้นทาง** (`trails`) — deque จุดกึ่งกลางกล่องรายตัว วาดเป็น polyline สีตามสถานะ
  บอกว่าชิ้นนี้ถูกยกออกไปทางไหน กลับมาวางตรงไหน
- **`forget_seconds`** — id ที่ tracker แจกแล้วทิ้ง (แก้วโผล่แวบเดียว) ต้องหลุดจากเช็กลิสต์
  ไม่งั้นรายการจะยาวขึ้นเรื่อย ๆ จนอ่านไม่ได้ · **ที่ตรวจแล้วไม่ถูกลืม**
- **กรอบเหลือง = ยังไม่ตรวจ · กรอบเขียว + ✓ หลัง id = ตรวจแล้ว** (กรอบหนาขึ้นตอนมือจับอยู่)

ไม่ใช่เรื่องที่ควรทำให้แอปตาย)

## กติกาถือแก้ว
แกนเดียวกับโน้ตบุ๊ก — มืออยู่บนแก้ว ห่อด้วย `HoldState`
สิ่งที่เพิ่มเข้ามาไม่ได้ทำให้ *กฎ* ฉลาดขึ้น แต่ทำให้ *สัญญาณเข้ากฎ* ไม่หลุด:
- `CupMemory` — แก้อาการกล่องแก้วหายตอนมือกำบัง
- `hand_on_cup` เช็กจาก "จุดมืออยู่บน/ข้างแก้ว (เผื่อขอบ) + ขนาดพอ ๆ กัน" แทน "มือกำ" — แก้วมีหู/ไม่มีหูก็จับได้
- `HoldState` ดูดซับเฟรมที่ pose/detection วืบหาย
- `Inspection` แปลง "ตอนนี้ถืออยู่" (ชั่วขณะ) เป็น "ตรวจไปแล้ว" (ข้อเท็จจริงที่ค้างอยู่)
  ซึ่งเป็นสิ่งที่คนสั่งงานถามจริง ๆ

**ประเด็นที่ต้องเน้นหน้าห้อง: กฎเท่าเดิม — ที่เพิ่มคือ thread + state + memory รอบ ๆ กฎ**

## สิ่งที่จงใจไม่ทำ
- ไม่ทำ installer / py2app / PyInstaller — วิทยากรรัน `python app/app.py` เอง
- ไม่ใช้ GUI framework ที่ต้องติดตั้ง (Qt/Electron) — Tkinter มากับ Python อยู่แล้ว
- ไม่มี scrollbar ในเช็กลิสต์ — เดโมมีของ 3-5 ชิ้น เกิน ~10 ค่อยใส่
- ไม่ re-identify แก้วข้ามการหายไปนาน ๆ (ต้องใช้ appearance feature) — แก้วที่หายเกิน
  `forget_seconds` แล้วกลับมา ถือเป็นชิ้นใหม่
- ONNX/OpenVINO เป็น *ทางเลือก* ผ่าน `tools/optimize.py` (บาง CPU เร็วขึ้น บางเครื่องไม่) ไม่ใช่ค่า default
- ไม่รองรับหลายกล้อง
- ไม่บันทึกวิดีโอ/log ลงไฟล์ — `s` เซฟภาพนิ่งพอแล้ว (เซฟเฉพาะภาพกล้อง ไม่รวมแผงข้าง)

## เกณฑ์ว่าเสร็จ

- [ ] ขยับแก้ว → กล่องตามทัน (ไม่ค้างที่ตำแหน่งเก่า) · จอเดิน ≥ ~10 fps บนเครื่องที่จะใช้
- [ ] ป้าย HOLDING ไม่กระพริบเมื่อถือแก้วนิ่ง
- [ ] ถอดปลั๊กกล้องแล้วเสียบกลับ → กลับมาทำงานเองโดยไม่ต้องรีสตาร์ท
- [ ] แก้วสองใบพร้อมกัน แต่ละใบมี ID ของตัวเองที่ไม่สลับกัน
- [ ] เอามือกวาดผ่านหน้าแก้วเร็ว ๆ → **ไม่ติ๊ก** · หยิบขึ้นมาดูจริง ~1 วิ → **ติ๊ก**
- [ ] ติ๊กแล้ววางคืน → ยังติ๊กอยู่ · กด R → รายการล้าง กลับมานับใหม่จาก 0
